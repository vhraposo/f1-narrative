# V3.24.3 — Personalidade em Pista / Fora das Pistas

## Objetivo

Separar traços de personalidade por contexto de atuação, mantendo o comportamento do personagem
limitado ao contexto de pista e permitindo ao usuário editar traços sociais fora das pistas.

## Modelo

- `PersonaTrait.context`: `ON_TRACK` (padrão) | `OFF_TRACK`.
- Unique alterado de `(personaId, key)` para `(personaId, key, context)` — o mesmo trait (ex.: `humor`)
  pode existir nos dois contextos sem colisão.
- Campos existentes preservados: `value`, `confidence`, `sourceKind` (`MANUAL` | `EVIDENCE`),
  `evidenceId`.

## API

- `PATCH /api/characters/:characterId/persona` aceita `traits[]` com `context` opcional
  (default `ON_TRACK`); duplicidade no payload é validada por `key:context`.
- `DELETE /api/characters/:characterId/persona/traits/:traitKey?context=OFF_TRACK`
  (default `ON_TRACK` para compatibilidade).
- `GET` retorna `context` em cada trait.

## Comportamento

Somente `ON_TRACK` alimenta o comportamento do personagem:

- `generation.assembly.ts` (prompt do personagem falante).
- `pilot-context.resolver.ts` (contexto de piloto para conversas).
- `persona-evolution.service.ts` (evolução por experiências).
- Reconciliador de evidências (`persona.service.ts`) continua operando em `ON_TRACK`;
  evidências públicas representam o comportamento observável em pista.

Traços `OFF_TRACK` são narrativos/sociais: visíveis e editáveis no editor, mas não alteram fala,
contexto ou evolução do personagem.

## UI (aba Personalidade)

- Aba renomeada de "Persona" para "Personalidade" (página do piloto e seção do personagem).
- Traços agrupados em **Em pista** e **Fora das pistas**; cada grupo tem estado vazio próprio.
- Formulário de adicionar com seletor de contexto; editar/remover operam no contexto do traço.
- Provenance mantida nos badges: "Manual" / "Baseada em evidência".
- Vazio total: "Esta personalidade ainda não possui traços definidos."
