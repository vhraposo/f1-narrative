## 4. Universalidade comprovada

- Nenhuma lógica condicional por piloto foi adicionada (o diff é dados + testes; a única mudança de código foi o refinamento genérico do fallback rico: país de nascimento não é mais inferido da nacionalidade e a frase de equipes ficou legível).
